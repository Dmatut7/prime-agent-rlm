# Walkthrough 矩阵 v1（每波走查的固定格子）

每个 wave 的 UX/走查 lane 按这张表走，不许只走主流程。P0 = 每波必过；P1 = 每周至少一次；
P2 = 变更波及才过。末尾的「CI 未覆盖」节是诚实清单——没人走的格子要写在里面。

| 格子 | 级 | 怎么走 |
|---|---|---|
| 冷启动首帧（120x40 + 80x24） | P0 | tmux 起 TUI，首帧出现即截屏 |
| 发消息+流式渲染+退出 | P0 | 一条消息等回复，Ctrl+C×2 退出带 resume 提示 |
| attach/resume 旧会话 | P0 | 起第二个客户端 attach 同会话，两侧各发一条 |
| /model 切换（含同模型重选） | P0 | 切一次，通知/账单行各恰一条 |
| 子代理派出+收编+alt+x 停 | P0 | 派一个轻的，状态行齐，二击停 |
| /new /fork 会话切换 | P1 | 切走后切回，内容与状态不丢不双 |
| 加载更早 + 回底指示 | P1 | 长会话往上翻，「↓ N 行新内容」出现且可回底 |
| Ctrl+Z 挂起 + fg 恢复 | P1 | 挂起后 shell 提示符干净，恢复后正常 |
| 超宽度档（80x24）渲染 | P1 | 关键界面在窄档不破版 |
| daemon 新旧组合（老 daemon + 新客户端） | P1 | 跨版本 attach 不崩、能力降级不报错 |
| 暖池命中 | P2 | 连发两会话，第二个受理 <150ms |
| 关停/重启 daemon | P1 | shutdown 后再起，会话可 resume |

## CI 未覆盖（诚实节）

- Windows 全格（无 runner）。
- kitty/Ghostty/WezTerm 真终端的键位协议（CI 全是假终端）。
- 真付费模型的长程任务（考题集只跑 $0 档）。
