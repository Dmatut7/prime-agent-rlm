# U6 状态区字符宽度口径（盲区①，2026-09-22）

千问评审盲区①：底部状态区使用的图形字符 `●`（U+25CF）、`│`（U+2502）、`─`（U+2500）、`↓`（U+2193）、`⚠`（U+26A0）均为 Unicode **East Asian Ambiguous** 宽度类——CJK 宽度终端可能按 2 列绘制，而本仓 pi-tui 的 `visibleWidth` 按 **1 列（窄档）** 计。

**施工口径（钉死）**：状态区一律按窄档（1 列）测量与布局；降级梯的列宽判据（②行 80 列、水位条 80 列门槛、提示行分段梯）全部基于 `visibleWidth` 的窄档读数。极端窄窗（<40 列）下 CJK 双宽终端可能出现 1–2 列错位——由既定降级梯先行掉条/掉段规避，不为二义宽度换字形。K3 评审 S11 的分层口径采纳：装饰图标白名单 `⚙●↓`；水位条图形字符 `─●│` 与警示符 `⚠` 属功能图形，不占白名单；融合态（水位顶到压缩位的末格）以 `●` 染 warning 色表达（千问 P1-A 官方备选之一），不引入新字形。
