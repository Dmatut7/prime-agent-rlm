## 度量

## 阈值 τ = 0.40 的对账依据

全库 1,225,809 个有共享词对的 title+content 余弦直方图：

| 分数带 | 对数 | 抽验结论 |
|---|---|---|
| ≥0.61 | 34 | 逐对目验全是真近重复（同日重写、v1/v2 分裂、日期后缀重写） |
| [0.40, 0.61) | 5 | 4 真（引文核对三坑 0.615、playwright_mcp坑位 0.613、图床去标识 0.416、console批施工 0.405）+ 1 边界（sales_ai教材面 0.422） |
| [0.31, 0.40) | 2 | 皆假（封测对攻 0.311、agents_md/k3 0.310——同主题不同条目） |
| 0.2 带 | 126 | 相关而非重复为主 |
| 0.1 带 | 3232 | 假阳性主体 |

**(0.311, 0.405) 是真空带**，τ 取 0.40 落在带顶：真阳性 39 对中 38 对正确
（精度 ≈97%），≥0.55 类全收。告警是建议性的（不阻止写入），边界误报成本 = 一行
可忽略的回执文字。

## 已知限制（对账发现的硬事实）

「大白话纪律」5 条语义重写链（老板「没听懂」事件链，09-07/09-19×2/09-29/10-03）
两两余弦只有 **0.02–0.11**：每篇都是同一条纪律的长文重新措辞，词面重叠被长文
norm 稀释。任何词面阈值要收它们就得放进 0.1 带的 3232 对假阳性——不可行。
本闸收的是 wave-10 实测的 28 组**机械重写**类（同日近重复），不收语义重述类；
后者需要 embedding 级手段（会引入新依赖，超出本任务范围）。

备选度量同样对账过并被否：

- 双向 containment（min norm）：[0.35, 0.70) 带 30 对里多数是假阳性
  （stock phrase 共享的纪律条目互相覆盖），精度崩。
- title-only 余弦：大白话链最高只有 0.33，且全库 [0.35,0.55) 带混入真不同条目。
- 单向候选覆盖率：漏掉「新条目是旧条目超集重写」方向（引文核对对只有 0.394）。
