- Fixed Anthropic turns ending with `model_context_window_exceeded` (or any stop reason the SDK does not know yet) being thrown away as a generic error; the exceeded-window reason now maps to length, and unrecognized reasons surface as a classified error carrying the raw reason.
- Fixed the Codex provider bypassing the shared provider-request budget: every fetch/WebSocket attempt now counts into the chain budget and is reported via `onProviderRequestAttempt`, and the attempt that spends the chain's last request is no longer retried or followed by a transport fallback.
- Fixed Codex responses truncated by the content filter being misreported as length (which drove automatic continuation into refusal loops); `response.incomplete` now keeps its own event type so content_filter surfaces as an error with the raw reason.
- Fixed azure-openai-responses requests omitting `store: false`, which made Azure retain full conversations server-side while the OpenAI Responses and Codex providers opt out.
- Fixed Google and Vertex prompt-level safety blocks being reported as malformed-stream truncations and retried as transient faults; `promptFeedback.blockReason` now surfaces as a safety-classified error carrying the provider's block reason.
- Fixed Anthropic streams from compatible proxies silently dropping content-block deltas/stops whose index matched no open block; each miss now persists an `anthropic_content_block_event_unrouted` diagnostic.
- Fixed OpenAI/Azure Responses requests for always-on reasoning models (`thinkingLevelMap.off === null`) not requesting `reasoning.encrypted_content` without an explicit effort, which left replayed thinking signatures without resumption material.
- Fixed `response.failed` frames discarding their usage, so failed Responses/Codex attempts now bill the tokens they burned.
- Fixed openai-completions replay joining an assistant turn's multiple text blocks without a separator, which fused abort traces directly onto reply text.
