- Added the optional `usageWindowTokens` model field: a config-declared rate-quota heuristic (the provider's token-per-time-window budget, e.g. 200k tokens/10s) that clamps the compaction trigger and the summarization budget below the declared context window. It is a heuristic, not a per-request limit - gateways accept single requests far larger than the quota, and their 429s cluster after large preceding prompts. Documented cost on a 1M-window model: a 200k cap moves the trigger from 700k to 140k (~5x more compactions), so it is an optional tuning knob, off by default.
