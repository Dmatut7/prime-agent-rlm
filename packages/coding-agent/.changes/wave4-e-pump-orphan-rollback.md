- Fixed a swallowed input: when the session-input pump early-returned on a busy slot (bash, retry, compaction, branch mutation), an action it had already selected at admission stranded in `selected` until the next unrelated input; the blocked pump now rolls the selection back into the queue and every busy-slot clear site reschedules the pump, so the turn dispatches as soon as the busy work ends. A `starts_when_admitted` agent message in the same window now gets a loud "Agent became busy" deferral error instead of hanging on a delivery promise that could never settle.
