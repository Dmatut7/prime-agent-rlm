- Fixed the RLM kernel harness store wedging permanently after one non-JSON-serializable entry write: `reference`/`arguments`/`metadata` are now validated as JSON-serializable before the write (the rejection names the offending field path), and a failed save rolls the in-memory mutation back so the store never diverges from disk.
- Fixed concurrent harness writes losing entries: sync+mutate+save now runs under a per-store thread lock plus a POSIX `flock` sidecar, so two kernels sharing the global store (RLM swarm) can no longer silently overwrite each other while both report success.
- Fixed `os.fork()`/multiprocessing children of the RLM kernel tearing the protocol: a forked child now detaches from the protocol fd, gets a fresh stream coalescer and write lock, and its stdout/stderr fall back to the captured pipes (delivered as unattributed output) instead of vanishing or interleaving with parent frames.
- Fixed harness memory writes made after their cell ended (detached tasks, background threads) never reaching the host: they are now buffered and reported at the next cell's start, with a bounded buffer that reports how many records were lost on overflow.
- Fixed the shell environment using the misspelled `GIT_TERMINAL_PROMPTS` (plural): agent shells now export the real `GIT_TERMINAL_PROMPT=0`, so git credential prompts fail fast instead of hanging on `/dev/tty`.
- Fixed several small kernel leaks and shutdown losses: late raw-fd output is drained at shutdown, finished cells drop their `linecache` entries, snapshot blob-cache entries are evicted when a name is rebound to a mutable or unpicklable value, bash status reads cap newline-free junk, orphan-journal enrollment without an owner pid fails closed, and bash spawned from a finished cell's detached task no longer resurrects that cell's interrupt bookkeeping.
