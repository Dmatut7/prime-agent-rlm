- Changed settings `packages` auto-install consent: missing **project-scope** packages (from a cloned repository's `.prime/settings.json`) are now skipped with a warning during session start instead of running an unattended `npm install`/`git clone`; install them explicitly with `prime-agent package install <source> --local`. User-scope and CLI-passed (`-e`) packages keep auto-installing, and resource loaders can now pass an `onMissingPackage` callback to ask.
- Fixed npm package specs that start with `-` (e.g. `npm:--registry=https://evil.tld`) being accepted from settings and forwarded to the npm command line, where npm would parse them as flags; they are now rejected with a diagnostic.
- Fixed `/login` and OAuth login reporting success when the credential store was corrupt or unwritable: the credential only lived in process memory and was lost on restart. Login now persists through a verified write (`setVerified`) that throws on load/write/read-back failure, and skipped optimistic writes are recorded to `drainErrors()`.
- Changed session transcript appends to fsync before close (`appendPrivateFile` gained a `durable` option), so a power loss can no longer drop turns the UI already showed as written.
- Fixed the `/share` preflight and trace-upload redaction missing the Prime CLI credential: `~/.prime/config.json`'s `api_key` (this fork's main Prime Inference credential, never stored in `auth.json`) is now part of the compared secret set.
