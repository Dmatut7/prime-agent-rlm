- Fixed the rebuilt context dropping real tool results when a model switch was recorded mid-tool-batch: the synthesized switch notice now waits behind the batch's tool results, and the post-compaction switch comparison seeds from before the retained window.
- Fixed fallback-chain and backup-model window checks after a compaction: they priced the context as 0 (or anchored on stale pre-compaction usage); a shared estimator now prices the current context by content, and an overflow compaction handoff no longer paints a fake "retry failed".
- Fixed provider-failure recovery turns suppressing self-recovery: an unattended recovery turn that ends by announcing the next step now gets its auto-continue (autonomous-loop suppression is unchanged).
- Fixed Esc during a retry countdown failing the active goal and restarting queued work: `abortRetry` now suspends the input pump and spares the goal like `abort()` does.
- Fixed aborted runs re-surfacing stale continuation messages after the next prompt: undelivered continuation products of an aborted run are dropped (and the goal continuation spend is repaid) instead of re-queued.
- Fixed persistent goals being unresumable at the token budget: `/goal resume` on a spent budget now says to extend it, and `/goal resume --budget <tokens>` extends and resumes. New goals no longer inherit the previous goal's continuation throttle clock, and Esc disarms an armed continuation wake.
