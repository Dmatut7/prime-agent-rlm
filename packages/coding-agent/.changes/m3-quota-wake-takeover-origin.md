- Fixed a quota-parked session never waking when the process restarted while the in-process wake timer had taken the resume over from the durable job: the takeover cancel was indistinguishable from a user cancellation, so the park (and its parkCount/wakeRetries budget) was silently dropped; cron job cancels now carry an origin stamp the restore path reads.
- Fixed a parked child session being permanently cancelled and misrecorded as user-aborted when an update restart aborted its in-flight wake probe: the RLM abort cascade now stamps `update_restart` on descendant turns instead of `user`, so the park's user-abort branch no longer eats the restart.
