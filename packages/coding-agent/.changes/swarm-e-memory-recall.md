- Fixed silent history loss from damaged session transcripts: a load that skips transcript lines now logs a warning with the file, the skipped-line count, and the first skip, and `getTranscriptLineSkips()` keeps the per-line file/line/reason record for the daemon and TUI.
- Added a deduplicated warning when rebuilding session context drops history: a broken parent chain (an entry whose parent is missing) or a compaction whose `firstKeptEntryId` anchor matches nothing on the walked path now names the broken link instead of silently serving a truncated context.
- Fixed the kernel snapshot dropping `_`-prefixed variables without a trace: they are now listed in the snapshot manifest's `skipped` with the private-name convention as the reason, like open file handles and non-string keys.
- Fixed the harness memory overview ranking entries by path first, which kept newer memories written under the default path out of the digest window; the window is now most-recently-updated first, and a truncated overview appends the id and title of every hidden entry so it stays reachable.
