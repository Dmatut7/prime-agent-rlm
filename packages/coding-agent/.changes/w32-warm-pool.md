- Added a warm spare pool to the daemon: one pre-booted worker per project directory (cwd-keyed, TTL 10min, cap 4) that a fresh session create claims after a connect+auth health check, cutting first-agent acceptance from ~265ms to ~105ms (median) on a warm daemon. Spares stay invisible to session listings and recovery until claimed; a claim requires an identical spawn cwd and a byte-identical process-environment fingerprint (auth, project, and client variables included), and any miss or unhealthy spare falls back to the cold launch. The pool drains on shutdown and before an update restart, releases spares under memory pressure, and never lets an unclaimed spare resurrect a dead supervisor. Disable with `PRIME_AGENT_WARM_POOL=0`.
