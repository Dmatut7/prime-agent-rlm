- Changed the session-hosting daemon's crash path: before a fatal `uncaughtException`/`unhandledRejection` takes the process down, it now writes the error with its stack plus the in-flight session inventory to the daemon log, re-checkpoints any session whose recovery-journal record drifted from its real busy state, and fsyncs the journal — so the supervisor's worker-death recovery (interruption marker plus the automatic resume prompt on rebind) has complete, honest input even for a crash.
