- Fixed threshold auto-compaction staying silent after a provider reply that reports zero token usage (CC 2.1.288): a zero-usage reply no longer anchors the context estimate at zero, so the trigger prices the session from the last real usage or by content density instead of skipping until the provider answers prompt-too-long.
- Added one fallback-model retry when the summarization request of a compaction is refused (CC 2.1.282): the next usable `providerFallbackModels` entry gets a single attempt, and only its failure - or having no fallback at all - counts toward the compaction failure streak.
