- Changed the `artifact-total-cap` retention class to reclaim only cold sessions' `kernel-state.dill` payloads (largest first) instead of whole artifact directories, so the 8 GiB backstop can no longer delete a resumable session's harness memory or pasted images; bytes the sweep may not reclaim (protected sessions, harness stores, transcripts, images) no longer count toward `retention.sessionArtifactsMaxBytes`, and nested session-artifact roots are counted once instead of twice.
