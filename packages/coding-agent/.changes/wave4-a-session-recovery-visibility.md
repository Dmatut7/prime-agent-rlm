- Changed the truncated-output continuation (`stopReason: "length"`) to no longer require tool work in the turn: a long answer the output budget cut off mid-sentence now resumes from where it stopped within the same `selfRecovery.maxAutoContinues` budget, and a subagent cut off while it still owes its parent a result is resumed under that budget too, with the continuation telling it to send the result before stopping.
- Fixed quota-park wake re-arm and navigation-rebuild entries dropping the `provider` field, so the parked-session status (the daemon's `quota_park_status` and the TUI countdown) keeps naming the provider after a re-arm or a restart.
- Fixed the emergency context shrink breaking the compaction ledger chain: its compaction entry now adopts the newest superseded compaction's `details` (fact/user-request ledgers, file lists, generation), so the next compaction continues the chain instead of re-parsing rendered summary blocks.
- Added a user-visible transcript notice when a session loads with a damaged transcript (unreadable lines, a broken entry chain, or an unresolvable compaction retention anchor): the notice names the damage, states that history before the damaged point is not in the model's context, and is deduped across resumes of the same damage. Previously this loss only appeared in logs.
