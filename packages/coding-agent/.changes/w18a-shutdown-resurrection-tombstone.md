- Fixed `shutdown` being undone by a daemon reviving itself afterwards: a supervisor that exits intentionally now leaves a per-socket shutdown tombstone, and worker-driven supervisor relaunches honor it (a relaunch-spawned daemon refuses the socket at ownership time; only an explicit start lifts the marker).
- Fixed workers spawning a replacement supervisor into a succession gap (update handoffs, hidden-supervisor takeovers): the worker's resurrection loop now waits out a 5s grace of continuous supervisor absence before launching, so a booting successor is no longer mistaken for a crash.
