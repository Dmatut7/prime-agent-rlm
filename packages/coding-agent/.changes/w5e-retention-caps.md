- Added a total-byte ceiling for the session-artifact tree (`retention.sessionArtifactsMaxBytes`, default 8 GiB): over the ceiling the retention sweep reclaims the coldest non-live session artifact directories oldest-first, keeping resident/leased/ledger-live sessions, pending cron jobs, live child transcripts, and anything younger than `retention.sessionArtifactsCapMinAgeDays` (default 7); a reclaimed session still resumes from its transcript with an empty kernel.
- Added a count cap for `pi-bash-*.log` tool-output temp files (`retention.bashTempFileMaxCount`, default 100): past the cap the oldest files beyond the cooldown floor are reclaimed, complementing the existing age window and per-file write cap.
- Added a deduplicated warning when a delete tombstone suppresses recreation of a deleted session's artifact directory, so the suppression is on record instead of silent.
