- Changed the auto-compaction toggle (自动压缩 in /settings, RPC `set_auto_compaction`) to save per model: the switch writes the serving model's entry under `compaction.perModel` ("provider/id"), models without an entry keep following the bare `compaction.enabled` default, and session state (`autoCompactionEnabled`) now reports the value resolved for the current model — wire shapes unchanged, older settings.json files need no migration. To switch auto-compaction off for every model, set `compaction.enabled: false` in settings.json.
