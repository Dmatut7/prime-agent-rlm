- Fixed the auto-continue notice claiming a hardcoded budget of 2: it now names the configured `selfRecovery.maxAutoContinues`.
- Fixed the bad-tool-call fallback storm counting legitimate zero-argument tool calls: the session resolves the tool's schema and only counts an empty-args error when the tool actually declares required parameters.
- Changed the daemon's depth-0 stall recovery to default on: an unattended session that stays silent past the stall warning is interrupted and handed a recovery instruction, while an attached client gets a 25-minute human window in which any input cancels the action (`stallWatchdog.rootRecovery.enabled: false` restores warn-only; `stallWatchdog.rootRecovery.humanWindowSeconds` retunes the window).
- Fixed overflow recovery giving up after a single compact-and-retry: a second context overflow now spends one emergency context shrink and retries on the shrunken context before the session goes terminal.
- Added a user-visible transcript notice naming the kernel variables the post-compaction snapshot deleted for exceeding the per-variable size limit, why they were deleted, and how to recreate them (previously model-only via the hidden `<ipython_state>` block).
- Changed the default autonomous run budgets to 20 continuations / 50 turns / 400k tokens / 2 hours (from 3 / 12 / 80k / 30 minutes); explicit `--autonomous-*` flags and `autonomous.*` settings still win.
