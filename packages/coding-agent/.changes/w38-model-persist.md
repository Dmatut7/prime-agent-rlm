- Added a parse-time preflight for `--model`: an unknown model or provider now errors immediately saying which, and a provider without credentials says so apart from "not found" - no more silent fallback to the default that only fails at the API with an auth error.
- Changed model selection to survive rejection honestly: a /model pick the server rejects reverts to the last serving model on disk and in settings (no restart-residue self-reporting the refused model); a transient or catalog-unreadable state never rewrites the saved choice (unknown is not a negative); a content refusal keeps the selection (the model answered); a saved default that cannot serve now falls back with an explicit message naming why.
