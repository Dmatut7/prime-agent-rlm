- Fixed held keybindings re-firing actions on Kitty keyboard protocol repeat events: `KeybindingsManager.matches` now ignores repeat events unless the action's definition sets `repeatable: true`, so holding a toggle key (e.g. ctrl+o / ctrl+t) flips it once instead of ping-ponging at the auto-repeat rate, while viewport scrolling, cursor movement, deletion and list navigation keep hold-to-repeat.
