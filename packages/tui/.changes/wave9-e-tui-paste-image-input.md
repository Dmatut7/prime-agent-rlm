- Fixed `/settings` search treating the space bar as "toggle the selected setting": while the search box is active, space and other printable characters go to the query (so multi-word labels can actually be found) and no setting is silently cycled; Enter still activates the selected row.
- Fixed inline Kitty/iTerm2 images whose leading blank rows scrolled above the visible window: the sequence line was repainted with a cursor-up clamped to the top edge, misplacing the image and shifting every row after it until the next full redraw. Such lines now degrade to an `[image]` placeholder.
- Fixed bracketed paste swallowing terminal probe answers that arrive mid-paste on slow links (Kitty keyboard flags, OSC 10/11 colors, cell size): they are diverted to their regular consumers instead of landing in the pasted text; a torn paste start marker now gets one extra completion window before falling back to key input, and a sequence cut short by an arriving paste start is emitted instead of dropped.
- Fixed fullscreen mouse handling on terminals without SGR reporting by parsing legacy X10 reports (click, drag, wheel), matching the existing X10 hover support.
- Fixed the fullscreen painter placing the hardware cursor past the right edge (column is now clamped to the frame width), and a transcript drag selection surviving a transcript rebuild: the selection is now cleared when the anchored rows change, so releasing it can no longer copy unrelated text.
